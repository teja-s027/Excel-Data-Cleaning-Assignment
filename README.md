Excel Data Cleaning and Transformation Assignment

Project Overview

This project demonstrates data cleaning and transformation techniques using Microsoft Excel.

Tasks Performed

- Handling Missing Values
- Correcting Inconsistent Data
- Removing Duplicate Records
- Splitting and Merging Columns
- Currency Formatting
- Date Formatting
- Conditional Formatting
- KPI Summary Creation

Tools Used

- Microsoft Excel

KPI Summary

- Total Records After Cleaning
- Duplicate Rows Removed
- Missing Values Filled
- Average Price
- Median Price
- Highest Price
- Lowest Price

Outcome

The dataset was successfully cleaned, transformed, formatted, and prepared for analysis and reporting.
